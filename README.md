# NEXORA — Digital Experience Studio

An interactive and futuristic portfolio website created by Mehemmed.

## About the Project

NEXORA is a modern web experience that combines creative web design, smooth animations, interactive UI components and responsive development.

## Features

* Futuristic dark-themed interface
* Animated particle background
* Interactive 3D-style project cards
* Responsive layout
* Smooth scrolling navigation
* Modern glassmorphism design
* HTML, CSS and JavaScript

## Technologies

* HTML5
* CSS3
* JavaScript
* Canvas API
* CSS 3D Transforms
